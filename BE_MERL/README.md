# BE PI3D sur MERL

Ce répertoire contient le code sur lequel on travail pour répondre au problème posé. Pour le moment, 3 pistes sont envisagées:

- Appliquer un MAE sur les données MERL -> cf dossier ```Piste_MAE```
- Utiliser les représentations latentes de BRDFs mesurées à l’aide de processus neuronaux -> cf dossier ```Piste_compact_representation```
- Utiliser des bouts de BRDF pour restituer celle-ci -> cf dossier ```Piste_sparse_brdf```
